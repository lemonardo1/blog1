## 주요 3D 모델 파일 형식

### **OBJ (.obj)**

- 가장 보편적인 3D 파일 형식 중 하나
- 정점, 텍스처 매핑 좌표, 다각형 면 등 기본적인 지오메트리 정보 포함
- 텍스처 정보는 보통 동반되는 MTL 파일에 저장
- 애니메이션 미지원
- 대부분의 3D 소프트웨어와 호환

### **FBX (.fbx)**

- Autodesk 형식으로 산업 표준으로 널리 사용됨
- 모델, 애니메이션, 리깅, 텍스처, 라이팅 등 복합적인 정보 포함
- 게임 엔진과의 호환성이 뛰어남 (Unity, Unreal Engine)
- 바이너리 및 ASCII 형식 지원

### **STL (.stl)**

- 3D 프린팅에 최적화된 형식
- 표면 지오메트리만 저장 (색상, 텍스처 등 미포함)
- 삼각형 메시로 구성된 간단한 구조
- 바이너리 및 ASCII 형식 지원

### **GLTF/GLB (.gltf/.glb)**

- "3D의 JPEG"라 불리는 웹 친화적 형식
- JSON 기반으로 경량화
- 모델, 텍스처, 애니메이션, 재질 등의 정보 포함
- GLB는 GLTF의 바이너리 버전으로 모든 리소스가 하나의 파일에 포함

### **3DS (.3ds)**

- 3D Studio Max의 레거시 형식
- 모델, 재질, 카메라, 조명 정보 등 포함
- 현대 표준에 비해 제한적이지만 여전히 널리 지원됨

### **BLEND (.blend)**

- Blender의 네이티브 파일 형식
- 모델, 애니메이션, 재질, 라이팅, 물리 등 모든 정보 포함
- Blender 외부에서는 제한적으로 지원됨

### **USD (.usd, .usda, .usdc, .usdz)**

- Universal Scene Description, Apple과 Pixar가 개발
- 복잡한 3D 장면과 워크플로우를 위한 고급 형식
- AR 콘텐츠에 점점 더 많이 사용됨 (특히 USDZ)

### **PLY (.ply)**

- Stanford Triangle Format 또는 Polygon File Format
- 3D 스캐너에서 주로 사용되는 형식
- 색상, 투명도, 표면 법선 등의 속성 지원
- 바이너리 및 ASCII 형식 지원

### **X3D (.x3d)**

- VRML의 후속 형식으로 웹용 3D 그래픽을 위한 XML 기반 형식
- 웹 브라우저에서 직접 렌더링 가능
- 인터랙티브 3D 콘텐츠 지원

### **ABC (.abc)**

- Alembic 파일 형식
- 복잡한 애니메이션 데이터를 저장하는 데 최적화
- VFX 및 애니메이션 산업에서 자주 사용

## DAE (Digital Asset Exchange) 파일

COLLADA (COLLAborative Design Activity)라는 XML 기반 스키마를 사용하는 3D 모델 파일 형식입니다. .rar는 이 파일이 RAR 압축 형식으로 압축되어 있음을 의미합니다.

DAE 파일의 주요 특징:

- XML 기반 파일 형식으로 텍스트 편집기에서 열어볼 수 있습니다
- 3D 모델, 애니메이션, 텍스처 정보 등을 포함합니다
- 다양한 3D 소프트웨어 간 호환성을 위해 설계되었습니다
- 게임 개발, 영화 제작, 건축 시각화 등 다양한 분야에서 사용됩니다

일반적으로 사용되는 다른 3D 모델 파일 형식들:

- OBJ: 간단한 지오메트리와 텍스처 정보를 포함하는 범용 형식
- FBX: Autodesk 형식으로 모델, 애니메이션, 리깅 등 포함
- STL: 3D 프린팅에 주로 사용되는 간단한 형식
- GLTF/GLB: 웹 기반 3D 콘텐츠 전송을 위한 현대적 형식
- 3DS: 3D Studio Max 기본 형식
- BLEND: Blender 기본 파일 형식

DAE 파일을 열거나 편집하려면 Blender, Autodesk Maya, 3ds Max, Cinema 4D 등의 3D 모델링 소프트웨어가 필요합니다.

각 형식은 특정 목적이나 워크플로우에 최적화되어 있으므로, 프로젝트 요구사항에 따라 적절한 형식을 선택하는 것이 중요합니다.
