## Blender 소개

Blender는 무료 오픈소스 3D 제작 소프트웨어로, 모델링, 리깅, 애니메이션, 시뮬레이션, 렌더링, 합성, 모션 트래킹, 비디오 편집 등 다양한 기능을 제공합니다. 게임 개발, 건축 시각화, 애니메이션 영화 제작 등에 널리 사용되고 있습니다.

## 인터페이스 기본 익히기

### 시작 화면

Blender를 처음 실행하면 시작 화면이 나타납니다. 여기서 '새 파일', '최근 파일 열기', '템플릿에서 시작' 등의 옵션을 선택할 수 있습니다.

### 주요 영역

- **3D 뷰포트**: 3D 객체를 보고 편집하는 주요 작업 공간
- **속성 패널**: 선택한 객체의 속성을 조정하는 패널
- **타임라인**: 애니메이션 작업을 위한 패널
- **아웃라이너**: 장면 내 모든 객체의 계층 구조를 보여주는 패널
- **노드 에디터**: 재질, 합성 등을 노드 기반으로 편집하는 공간

### 작업 공간 전환

화면 상단에 있는 탭을 클릭하여 레이아웃, 모델링, 스컬프팅, UV 편집, 텍스처 페인팅, 쉐이딩, 애니메이션, 렌더링 등 다양한 작업 공간으로 전환할 수 있습니다.

## 기본 조작법

### 객체 선택 및 변형

- **선택**: 객체를 클릭하여 선택
- **이동**: G 키를 누른 후 마우스 이동
- **회전**: R 키를 누른 후 마우스 이동
- **크기 조절**: S 키를 누른 후 마우스 이동
- **축 제한**: 변형 시 X, Y, Z 키를 눌러 특정 축으로 제한

### 뷰포트 탐색

- **회전**: 마우스 중간 버튼 클릭 후 이동
- **이동**: Shift + 마우스 중간 버튼 클릭 후 이동
- **확대/축소**: 마우스 휠 스크롤 또는 Ctrl + 마우스 중간 버튼 클릭 후 이동
- **뷰 리셋**: 홈 키
- **카메라 뷰**: 숫자패드 0
- **정면/측면/윗면 뷰**: 숫자패드 1, 3, 7

## 3D 모델링 기초

### 기본 메시 추가

1. Shift + A를 눌러 추가 메뉴 열기
2. 메시 카테고리에서 원하는 기본 형태 선택 (큐브, 구, 원통 등)

### 편집 모드

1. 객체를 선택한 상태에서 Tab 키를 눌러 편집 모드 진입
2. 정점(Vertex), 엣지(Edge), 페이스(Face) 선택 모드 전환: 1, 2, 3 키
3. 정점/엣지/페이스 선택: 클릭
4. 여러 요소 선택: Shift + 클릭

### 주요 모델링 도구

- **돌출(Extrude)**: E 키
- **루프 컷(Loop Cut)**: Ctrl + R
- **병합(Merge)**: 정점 선택 후 Alt + M
- **채우기(Fill)**: 엣지 선택 후 F 키
- **세분화(Subdivide)**: 선택 후 우클릭 메뉴에서 세분화 선택

## 재질과 텍스처

### 기본 재질 생성

1. 객체 선택
2. 속성 패널에서 재질 탭 선택
3. '+ 새 재질' 버튼 클릭

### 노드 기반 재질 편집

1. 쉐이딩 작업 공간으로 전환
2. 노드 에디터에서 재질 노드 편집

### 텍스처 적용

1. 재질에 이미지 텍스처 노드 추가
2. UV 편집 작업 공간에서 UV 맵 조정

## 라이팅

### 조명 추가

1. Shift + A를 눌러 추가 메뉴 열기
2. 조명 카테고리에서 원하는 조명 유형 선택 (포인트, 스팟, 썬 등)

### 조명 속성 조정

- 강도, 색상, 그림자 설정 등을 속성 패널에서 조정

## 렌더링

### 렌더링 엔진 선택

- Eevee: 실시간 렌더링, 빠름
- Cycles: 물리 기반 렌더링, 사실적이지만 느림

### 렌더링 설정

1. 속성 패널에서 렌더링 탭 선택
2. 해상도, 샘플링, 출력 경로 등 설정

### 렌더링 실행

- 단일 프레임 렌더링: F12
- 애니메이션 렌더링: Ctrl + F12

## 애니메이션 기초

### 키프레임 설정

1. 타임라인에서 원하는 프레임으로 이동
2. 객체 위치/회전/크기 등 조정
3. I 키를 눌러 키프레임 추가 메뉴 열기
4. 키프레임 유형 선택 (위치, 회전, 크기 등)

### 애니메이션 커브 편집

1. 그래프 에디터 작업 공간으로 전환
2. 키프레임 커브를 편집하여 애니메이션 타이밍 조정

## 유용한 단축키

- **Shift + A**: 객체 추가
- **X**: 선택한 객체 삭제
- **Tab**: 편집 모드 전환
- **G, R, S**: 이동, 회전, 크기 조절
- **Ctrl + Z**: 실행 취소
- **Ctrl + Shift + Z**: 다시 실행
- **H**: 선택한 객체 숨기기
- **Alt + H**: 숨긴 객체 표시
- **N**: 속성 사이드바 토글
- **T**: 도구 사이드바 토글
- **Z**: 쉐이딩 모드 전환 메뉴

## 초보자를 위한 팁

1. **튜토리얼 활용하기**: Blender 공식 사이트와 YouTube에는 많은 튜토리얼이 있습니다.
2. **단축키 익히기**: Blender는 단축키 기반 워크플로우가 효율적입니다.
3. **작은 프로젝트부터 시작하기**: 처음부터 복잡한 모델을 만들려고 하지 마세요.
4. **참조 이미지 사용하기**: 모델링 시 참조 이미지를 배경으로 설정하면 도움이 됩니다.
5. **저장 습관 들이기**: Ctrl + S로 자주 저장하고, 백업 파일을 만드는 습관을 들이세요.
6. **커뮤니티 활용하기**: Blender 커뮤니티는 매우 활발하므로 질문이나 문제가 있으면 도움을 구하세요.

이 가이드는 Blender의 기초적인 사용법을 다루고 있습니다. Blender는 매우 강력하고 다양한 기능을 제공하는 소프트웨어이므로, 계속해서 학습하고 연습하면 점차 숙련되어 갈 것입니다.
