Amazon web services
## A

**Activate for Startups**: 스타트업이 AWS에서 구축하고 성장하는 데 도움이 되는 리소스를 제공합니다.

**AWS Amplify**: 풀스택 개발자를 위한 웹 호스팅 및 앱 백엔드 서비스를 제공합니다.

**API Gateway**: API를 구축, 배포 및 관리할 수 있습니다.

**AWS App Mesh**: 마이크로서비스를 쉽게 모니터링하고 제어할 수 있습니다.

**AWS App Runner**: 프로덕션 웹 애플리케이션을 규모에 맞게 구축하고 실행할 수 있습니다.

**AWS App Studio**: 생성형 AI를 활용하여 비즈니스 문제를 해결하는 안전한 애플리케이션을 구축합니다.

**AWS AppConfig**: 기능 플래그, 운영 플래그 및 기타 런타임 구성을 사용하여 프로덕션 환경에서 빠르고 안전하게 변경할 수 있습니다.

**AWS AppFabric**: SaaS 애플리케이션을 연결하여 생산성과 보안을 향상시킵니다.

**Amazon AppFlow**: 코드 없이 앱을 통합하고 데이터 흐름을 자동화합니다.

**Application Discovery Service**: 온프레미스 애플리케이션 인벤토리 및 종속성을 검색합니다.

**AWS Application Migration Service**: AWS 애플리케이션 마이그레이션 서비스(MGN)는 리프트 앤 시프트 마이그레이션을 자동화합니다.

**Application Recovery Controller**: 애플리케이션 복구 준비 상태를 모니터링하고 장애 조치를 관리합니다.

**AppStream 2.0**: 데스크톱 애플리케이션을 모든 웹 브라우저에 안전하게 스트리밍합니다.

**AWS AppSync**: 모바일 및 웹 앱을 위한 GraphQL을 사용한 실시간 데이터 동기화(온라인 또는 오프라인).

**AWS Artifact**: 보안 규정 준수 보고서 및 계약을 제공합니다.

**Athena**: 서버리스 대화형 분석 서비스입니다.

**AWS Audit Manager**: 위험 및 규정 준수를 위한 제어를 지속적으로 평가합니다.

**Amazon Augmented AI**: 기계 학습 예측에 대한 인적 검토를 쉽게 구현합니다.

**Aurora and RDS**: 관리형 관계형 데이터베이스 서비스입니다.

**Aurora DSQL**: 사실상 무제한 확장성, 높은 가용성 및 인프라 관리가 필요 없는 서버리스 분산 SQL 데이터베이스입니다.

**AWS Auto Scaling**: AWS에서 전체 애플리케이션을 빠르게 확장할 수 있습니다.

## B

**AWS B2B Data Interchange**: 클라우드 규모로 EDI 기반 워크플로우를 구축하고 실행합니다.

**AWS Backup**: AWS 서비스 전반에 걸쳐 백업을 중앙에서 관리하고 자동화합니다.

**Batch**: 모든 규모에서 완전히 관리되는 배치 처리를 제공합니다.

**Amazon Bedrock**: 기초 모델(FM)을 사용하여 생성형 AI 애플리케이션을 구축하고 확장하는 가장 쉬운 방법입니다.

**Billing and Cost Management**: 청구서를 보고 지불하며, 지출을 분석하고 관리하며, 비용을 최적화합니다.

**AWS Billing Conductor**: 청구 관행을 단순화합니다.

**Amazon Braket**: 양자 컴퓨팅을 탐색, 평가 및 실험하기 위한 서비스입니다.

## C

**Certificate Manager**: SSL/TLS 인증서를 프로비저닝, 관리 및 배포합니다.

**Amazon Chime**: Amazon Chime은 온라인 회의를 변화시키는 커뮤니케이션 서비스입니다.

**Amazon Chime SDK**: 애플리케이션을 위한 실시간 통신을 제공합니다.

**AWS Clean Rooms**: 기본 원시 데이터를 공유하거나 공개하지 않고 집합적 데이터 세트에서 쉽고 안전하게 협업할 수 있습니다.

**AWS Cloud Map**: 클라우드의 동적 맵을 구축합니다.

**Cloud9**: 코드 작성, 실행 및 디버깅을 위한 클라우드 IDE입니다.

**CloudFormation**: 템플릿으로 리소스를 생성하고 관리합니다.

**CloudFront**: 글로벌 콘텐츠 전송 네트워크입니다.

**CloudHSM**: 클라우드에서 관리되는 하드웨어 보안 모듈입니다.

**CloudSearch**: 관리형 검색 서비스입니다.

**CloudShell**: AWS 관리 콘솔에서 AWS CLI 액세스가 가능한 브라우저 기반 셸입니다.

**CloudTrail**: 사용자 활동 및 API 사용을 추적합니다.

**CloudWatch**: 리소스 및 애플리케이션을 모니터링합니다.

**CodeArtifact**: 소프트웨어 개발을 위한 안전하고 확장 가능하며 비용 효율적인 아티팩트 관리를 제공합니다.

**CodeBuild**: 코드를 빌드하고 테스트합니다.

**Amazon CodeCatalyst**: 통합 DevOps 서비스입니다.

**CodeCommit**: 비공개 Git 저장소에 코드를 저장합니다.

**CodeDeploy**: 코드 배포를 자동화합니다.

**Amazon CodeGuru**: 현대적인 애플리케이션 구축 및 실행을 위한 지능형 권장 사항을 제공합니다.

**CodePipeline**: 지속적 전달을 사용하여 소프트웨어를 릴리스합니다.

**Cognito**: 소비자 신원 관리 및 페더레이션 ID를 위한 AWS 자격 증명을 제공합니다.

**Amazon Comprehend**: 비정형 텍스트를 분석합니다.

**Amazon Comprehend Medical**: Amazon Comprehend Medical은 기계 학습을 사용하여 의료 텍스트에서 인사이트와 관계를 추출합니다.

**AWS Compute Optimizer**: 워크로드에 최적의 AWS 컴퓨팅 리소스를 추천합니다.

**AWS Config**: 리소스 인벤토리 및 변경 사항을 추적합니다.

**Amazon Connect**: Amazon Connect는 모든 규모의 참여를 가능하게 하는 컨택 센터입니다.

**Console Home**: 리소스 인사이트, 서비스 바로 가기 및 기능 업데이트를 볼 수 있습니다.

**Control Tower**: 안전하고 규정을 준수하는 다중 계정 환경을 설정하고 관리하는 가장 쉬운 방법입니다.

## D

**AWS Data Exchange**: 제3자 데이터를 쉽게 찾고, 구독하고, 사용할 수 있습니다.

**Amazon Data Firehose**: 모든 데이터에 대해 저비용으로 모든 규모에서 실시간 스트리밍 전송을 제공합니다.

**AWS Data Transfer Terminal**: 클라우드로의 고처리량 전송을 위한 위치입니다.

**Database Migration Service**: 관리형 데이터베이스 마이그레이션 서비스입니다.

**DataSync**: 데이터 이동을 단순화, 자동화 및 가속화합니다.

**Amazon DataZone**: 내장된 거버넌스로 조직 경계를 넘어 데이터를 활용합니다.

**AWS Deadline Cloud**: 단순화된 렌더 관리를 제공합니다.

**AWS DeepComposer**: AWS DeepComposer는 모든 기술 수준의 개발자가 생성형 AI를 시작할 수 있게 해줍니다.

**AWS DeepRacer**: 기계 학습으로 구동되는 완전 자율 1/18 스케일 레이스 카입니다.

**Detective**: 잠재적인 보안 문제를 조사하고 분석합니다.

**Device Farm**: 실제 기기에서 Android, iOS 및 웹 앱을 테스트합니다.

**Amazon DevOps Guru**: 애플리케이션 가용성을 향상시키기 위한 ML 기반 클라우드 운영 서비스입니다.

**Direct Connect**: AWS에 대한 전용 네트워크 연결을 제공합니다.

**Directory Service**: Active Directory를 호스팅하고 관리합니다.

**Amazon DocumentDB**: 완전 관리형 MongoDB 호환 데이터베이스 서비스입니다.

**DynamoDB**: 관리형 NoSQL 데이터베이스입니다.

## E

**EC2**: 클라우드의 가상 서버입니다.

**EC2 Global View**: EC2 글로벌 뷰는 모든 AWS 리전에서 EC2 및 VPC 리소스를 찾고 볼 수 있는 글로벌 대시보드 및 검색 기능을 제공합니다.

**EC2 Image Builder**: OS 이미지 빌드, 사용자 정의 및 배포를 자동화하는 관리형 서비스입니다.

**EFS**: EC2용 관리형 파일 스토리지입니다.

**Elastic Beanstalk**: 웹 앱을 실행하고 관리합니다.

**Elastic Container Registry**: 완전 관리형 Docker 컨테이너 레지스트리로, 공개 또는 비공개로 컨테이너 소프트웨어를 공유하고 배포합니다.

**Elastic Container Service**: 컨테이너를 실행하기 위한 매우 안전하고 신뢰할 수 있으며 확장 가능한 방법입니다.

**AWS Elastic Disaster Recovery**: AWS로의 확장 가능하고 비용 효율적인 애플리케이션 복구를 제공합니다.

**Elastic Kubernetes Service**: Kubernetes를 시작, 실행 및 확장하는 가장 신뢰할 수 있는 방법입니다.

**Elastic Transcoder**: 사용하기 쉬운 확장 가능한 미디어 트랜스코딩을 제공합니다.

**Amazon Elastic VMware Service**: AWS에서 VMware 워크로드를 마이그레이션하고 운영하는 가장 빠른 경로입니다.

**ElastiCache**: 인메모리 캐시를 제공합니다.

**Elemental Appliances & Software**: 비디오 처리 및 전달을 위한 온프레미스 솔루션입니다.

**EMR**: 관리형 Hadoop 프레임워크입니다.

**AWS End User Messaging**: 여러 통신 채널을 통해 고객과 소통합니다.

**AWS Entity Resolution**: 구성이 쉬운 기계 학습 기반 엔티티 해결 서비스입니다.

**Amazon EventBridge**: 이벤트 기반 애플리케이션 구축을 위한 서버리스 서비스입니다.

## F

**Amazon FinSpace**: 관리형 kdb 인사이트를 통한 자본 시장을 위한 데이터 처리 및 분석을 제공합니다.

**AWS Firewall Manager**: 방화벽 규칙의 중앙 관리를 제공합니다.

**AWS FIS**: 제어된 실험으로 복원력과 성능을 향상시킵니다.

**Amazon Forecast**: Amazon Forecast는 정확한 시계열 예측을 위한 완전 관리형 서비스입니다.

**Amazon Fraud Detector**: 기계 학습을 사용하여 온라인 사기를 더 빠르게 탐지합니다.

**FSx**: 다양한 워크로드에 최적화된 완전 관리형 타사 파일 시스템을 제공합니다.

## G

**Amazon GameLift Servers**: 세션 기반 멀티플레이어 게임을 배포하고 확장합니다.

**Amazon GameLift Streams**: 전 세계적으로 높은 프레임 속도, 낮은 지연 시간의 게임 스트리밍을 제공합니다.

**Global Accelerator**: AWS 글로벌 네트워크를 사용하여 애플리케이션의 가용성과 성능을 향상시킵니다.

**AWS Glue**: AWS Glue는 서버리스 데이터 통합 서비스입니다.

**AWS Glue DataBrew**: 분석 및 기계 학습을 위해 데이터를 정리하고 정규화하는 시각적 데이터 준비 도구입니다.

**Amazon Grafana**: 대화형 데이터 시각화 및 대시보딩을 위한 완전 관리형 Grafana 서비스입니다.

**Ground Station**: 위성과 통신합니다.

**GuardDuty**: AWS 계정 및 워크로드를 보호하기 위한 지능형 위협 탐지 서비스입니다.

## H

**AWS Health Dashboard**: AWS 서비스 상태에 대한 개인화된 보기를 제공합니다.

**AWS HealthImaging**: 의료 이미지를 저장, 분석 및 공유합니다.

**AWS HealthLake**: 건강 데이터의 의미를 파악합니다.

**AWS HealthOmics**: 오믹스 데이터를 인사이트로 변환합니다.

**Infrastructure Composer**: 시각적으로 현대적인 애플리케이션을 빠르게 설계하고 구축합니다.

**Amazon Inspector**: 규모에 맞는 지속적인 취약성 관리를 제공합니다.

**Amazon Interactive Video Service**: 관리형 대화형 라이브 스트림을 제공합니다.

**IoT SiteWise**: 산업 운영에서 데이터 기반 결정을 내립니다.

**IoT TwinMaker**: 운영을 최적화하기 위해 실제 시스템의 디지털 트윈을 쉽게 생성합니다.

**AWS IQ**: 외부 AWS 인증 전문가의 도움을 받아 프로젝트를 더 빨리 완료합니다.

## K

**Managed Services**: AWS를 위한 IT 운영 관리를 제공합니다.

**AWS Marketplace**: 소프트웨어를 찾고, 구매하고, 배포할 수 있는 디지털 카탈로그입니다.

**MediaTailor**: 채널 조립 및 서버 측 광고 삽입으로 멀티스크린 콘텐츠를 개인화하고 수익화합니다.

**Amazon MemoryDB**: 완전 관리형 Valkey 및 Redis OSS 호환 인메모리 데이터베이스 서비스입니다.

**AWS Migration Hub**: 데이터 센터를 AWS로 마이그레이션하는 과정을 단순화하고 가속화합니다.
