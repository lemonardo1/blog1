

코드 리팩토링은 소프트웨어의 외부 동작을 변경하지 않으면서 기존 소스 코드의 구조를 재구성하는 과정입니다.

- 소프트웨어의 설계, 구조 및 구현을 개선하되 기능은 보존함
- 코드 가독성 향상과 복잡성 감소를 통해 유지보수성 개선
- 더 단순하고 깔끔한 내부 아키텍처나 객체 모델을 만들어 확장성 개선
- 성능 향상 가능성 제공 (더 빠른 실행 또는 메모리 사용 감소)

리팩토링은 일반적으로 표준화된 기본 '마이크로-리팩토링'의 연속으로 적용됩니다. 각 마이크로-리팩토링은 소프트웨어의 동작을 보존하거나 최소한 기능적 요구사항을 변경하지 않는 작은 변화입니다.
