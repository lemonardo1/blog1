
## 1. Confocal Microscope LSM 980

### 특징

- 초고감도 32 channel spectral GaAsP-PMT detector 탑재
- 약한 시그널도 선명하게 이미징 가능
- Crosstalk 현상 없이 multi-spectral imaging 가능
- Airyscan2 mode로 X, Y, Z 축 1.7~2배 해상도 향상

### 핵심 사용법

1. **시스템 시작**
    
    - 레이저, 컴퓨터, 현미경 본체 순으로 전원 켜기
    - ZEN 소프트웨어 실행 후 로그인
2. **샘플 준비 및 장착**
    
    - 슬라이드 고정 클립으로 샘플 고정
    - 오일 사용 시 적정량만 사용 (과다 사용 주의)
3. **이미징 설정**
    
    - Acquisition 탭에서 레이저 선택 및 강도 조절
    - 형광 채널별 detector 감도 및 파장 범위 설정
    - Z-stack 촬영 시 상/하한 설정 후 간격 지정
4. **Airyscan2 모드 활성화**
    
    - Acquisition 탭에서 Airyscan 모드 선택
    - 이미지 최적화를 위한 Airyscan 파라미터 조정
    - Processing 탭에서 Airyscan 이미지 프로세싱 실행
5. **데이터 저장 및 시스템 종료**
    
    - 이미지는 CZI 형식으로 저장
    - 시스템 종료 시 레이저 끄기 → 소프트웨어 종료 → 컴퓨터 종료 → 현미경 전원 차단

## 2. Confocal Microscope LSM 780

### 특징

- PMT보다 약 2배 이상의 감도를 가진 GaAsP detector 장착
- 저발현 단백질이나 약한 신호 감지 가능
- 23개 detector로 형광물질의 스펙트럼 신속 분석

### 핵심 사용법

1. **시스템 준비**
    
    - 레이저 냉각기 확인 후 전원 켜기
    - ZEN 소프트웨어 실행
2. **레이저 및 검출기 설정**
    
    - Smart Setup에서 형광체 선택
    - 채널별 레이저 강도 및 검출 범위 설정
    - 고감도 모드 활성화 방법: Channels 탭에서 GaAsP 선택
3. **스캔 파라미터 조정**
    
    - 스캔 속도, 해상도, 픽셀 시간 설정
    - 이미지 평균화(averaging) 횟수 설정으로 노이즈 감소
4. **스펙트럼 분석**
    
    - Lambda mode 선택 후 스캔 범위 설정
    - 선택 영역에서 스펙트럼 프로파일 추출
    - Linear unmixing으로 겹치는 형광 신호 분리

## 3. Confocal Microscope LSM 710

### 특징

- 뛰어난 감도
- 7종류 레이저 광원 장착으로 다양한 형광시료에 적합
- 최상의 이미징 가능

### 핵심 사용법

1. **시스템 초기화**
    
    - 컴퓨터 및 현미경 전원 켜기
    - ZEN 소프트웨어 실행 및 시스템 초기화 대기
2. **광원 및 필터 설정**
    
    - 필요한 레이저 선택 (405, 458, 488, 514, 561, 594, 633nm)
    - 다이크로익 미러 및 필터 셋 선택
3. **이미지 획득**
    
    - 이미지 크기, 비트 깊이, 스캔 방향 설정
    - 핀홀 크기 조절 (광학 절편 두께 결정)
    - Time series 또는 Z-stack 모드 설정
4. **이미지 후처리**
    
    - 노이즈 감소 필터 적용
    - 이미지 컨트라스트 및 밝기 조정
    - 채널 간 색상 조정 및 병합

## 4. Confocal Microscope LSM 700

### 특징

- 4가지 레이저 (405, 488, 555, 639) 광원 장착
- 사용법이 비교적 간단
- z-stack, tile scan 등 고해상도 형광이미지 획득

### 핵심 사용법

1. **기본 설정**
    
    - 전원 켜고 10분 예열
    - 대물렌즈 선택 (10x, 20x, 40x, 63x)
2. **샘플 관찰**
    
    - Locate 탭에서 밝은 시야로 샘플 위치 확인
    - 초점 조절 후 형광 모드 전환
3. **이미징 최적화**
    
    - Range Indicator 사용하여 최적 레이저 강도 설정
    - Smart Setup으로 채널 간 간섭 최소화
4. **고급 이미징**
    
    - Tile scan: Navigation 탭에서 영역 지정
    - Z-stack: Z-Stack 탭에서 First/Last 위치 설정
    - Time series: Time Series 탭에서 간격과 횟수 설정
5. **데이터 내보내기**
    
    - 이미지 처리 후 TIFF, JPEG 등으로 내보내기
    - 분석 소프트웨어 호환 형식 선택

## 5. Two-photon Microscope FVMPE

### 특징

- 적외선 파장대의 femtosecond lasers 사용
- 조직 깊은 곳까지 excitation 가능
- 극대화된 detection sensitivity
- Intravital imaging에 최적화

### 핵심 사용법

1. **레이저 준비**
    
    - Mode-lock 확인 (Tsunami 및 MaiTai 레이저)
    - 파장 설정 (일반적으로 800-950nm)
2. **샘플 준비**
    
    - 적합한 챔버에 샘플 고정
    - 생체 샘플의 경우 생리학적 환경 유지
3. **이미지 획득 설정**
    
    - Galvano/Resonant 스캐너 선택
    - PMT 게인 및 오프셋 조정
    - Wavelength mixing으로 다중 형광체 이미징
4. **심부 조직 이미징**
    
    - Z 보정 기능으로 깊이에 따른 레이저 파워 자동 조정
    - 깊이에 따른 디텍터 감도 최적화
5. **장시간 생체 이미징**
    
    - 온도 및 CO2 제어 설정
    - 타임랩스 간격 및 총 시간 설정
    - 광독성 최소화를 위한 레이저 파워 최적화

## 6. THUNDER Imager

### 특징

- 8개 LED 광원 장착으로 다양한 형광 이미징
- H&E staining 등 면역 염색 시료의 컬러 촬영 가능
- 고속 촬영으로 live imaging 및 큰 시료 촬영에 유리
- Computational clearing 기술로 두꺼운 조직에서도 선명한 이미지

### 핵심 사용법

1. **시스템 설정**
    
    - LED 광원 예열 (약 5분)
    - LAS X 소프트웨어 실행
2. **이미징 모드 선택**
    
    - Widefield: 일반 형광 이미징
    - THUNDER: 두꺼운 샘플 또는 배경 제거 필요 시
    - Live: 실시간 세포 관찰 시
3. **Computational Clearing 설정**
    
    - 샘플 유형에 따라 Small Volume, Large Volume, Assay 중 선택
    - Rolling Ball 배경 제거 강도 조절
    - Deconvolution 강도 설정
4. **대용량 샘플 이미징**
    
    - Navigator로 전체 샘플 맵 생성
    - 관심 영역 설정 및 자동 타일 스캔
    - 자동 스티칭으로 전체 이미지 합성
5. **시계열 이미징**
    
    - 자동 초점 유지 설정
    - 시간 간격 및 총 촬영 시간 설정
    - 환경 제어 모듈 설정 (온도, CO2, 습도)
